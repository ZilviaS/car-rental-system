# Car Rental System

A full-stack web application for managing vehicle rentals, reservations, and customer information. The system provides role-based access for customers and administrators, allowing users to browse available vehicles, make reservations, and manage rental records through a responsive web interface

## Overview

Car Rental System is a full-stack web application developed to simplify the vehicle rental process for both customers and administrators. Customers can browse available vehicles, create rental reservations, and view their booking history. Administrators can manage vehicles, reservations, customers, and rental records through a dedicated dashboard.

The application follows a RESTful architecture with a responsive frontend and a backend API responsible for business logic, authentication, and database management.

## Features

- 🔐 User authentication and authorization
- 🚗 Vehicle management
- Vehicle availability management
- 📅 Vehicle reservation system
- 👤 Customer management
- 📋 Rental history management
- 🛡️ Role-based access control (Admin / Customer)
- 📱 Responsive user interface
